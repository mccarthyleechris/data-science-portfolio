# Data

Download the three Top 10 files from [Netflix Top 10](https://www.netflix.com/tudum/top10) and save them in this folder with these names:

- `all-weeks-global-netflix(Top 10).csv`
- `all-weeks-countries-netflix(Top 10).csv`
- `most-popular-netflix(Top 10).csv`

The notebook uses data from June 2023 to April 2024. Newer downloads include more weeks, so the numbers will shift slightly.
