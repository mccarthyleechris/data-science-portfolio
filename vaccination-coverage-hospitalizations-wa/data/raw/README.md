# Data

Save these files in this folder (`data/raw/`) with exactly these names.

**Vaccination coverage** (13 tables), from
[WA DOH Respiratory Immunization Data](https://doh.wa.gov/data-and-statistical-reports/health-behaviors/immunization/respiratory-immunization-data):

- `COVID-19Table2CoverageByCounty.csv`
- `COVID-19Table3CoverageByRaceEthnicity.csv`
- `COVID-19Table4CoverageByAgeGroup.csv`
- `COVID-19Table5CoverageBySex.csv`
- `FluTable2CoverageByCounty.csv`
- `FluTable3CoverageByRaceEthnicity.csv`
- `FluTable4CoverageByAgeGroup.csv`
- `FluTable5CoverageBySex.csv`
- `AdultRSVTable3CoverageByRaceEthnicity.csv`
- `AdultRSVTable4CoverageBySex.csv`
- `PediatricRSVTable2CoveragebyCounty.csv`
- `PediatricRSVTable3CoverageByRaceEthnicity.csv`
- `PediatricRSVTable4CoverageBySex.csv`

**Hospitalizations**, from the
[WA DOH Respiratory Illness Data Dashboard](https://doh.wa.gov/data-and-statistical-reports/diseases-and-chronic-conditions/communicable-disease-surveillance-data/respiratory-illness-data-dashboard):

- `respiratory_hospitalizations_downloadable.csv`

The analysis used coverage data as of November 9, 2026 and hospitalization data updated October 13, 2026. The adult RSV county table was empty on the DOH site, so there's no file for it.
