# Data

Download the Electric Vehicle Population Data from
[data.wa.gov](https://data.wa.gov/Transportation/Electric-Vehicle-Population-Data/f6w7-q2d2)
(Export → CSV) and save it in this folder as `Electric_Vehicle_Population_Data.csv`.

The other two sources are pulled live by the notebook:
- The AFDC laws and incentives table is scraped from https://afdc.energy.gov/laws/matrix?sort_by=tech
- Charging stations come from the Open Charge Map API, which needs a free API key.
