# Data

Download these three files from the
[WA DOH Respiratory Illness Data Dashboard](https://doh.wa.gov/data-and-statistical-reports/diseases-and-chronic-conditions/communicable-disease-surveillance-data/respiratory-illness-data-dashboard)
and save them in this folder:

- `respiratory_hospitalizations_downloadable.csv`
- `respiratory_deaths_downloadable.csv`
- `data_dictionary_respiratory_surveillance.csv`

The analysis used the download updated October 13, 2026. DOH updates the dashboard regularly, so a newer download will include more weeks.
